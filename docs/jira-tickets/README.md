# Jira ticket working notes

Supporting material for individual Jira tickets lives in a folder named after the ticket key, for example `TCVP-3354/`. That material can include investigation SQL, data extracts with no personal information, and design notes.

- Create the folder when a ticket needs material that does not belong in code or permanent docs.
- Do not store real disputant data, credentials, or connection strings here.
- When a ticket produces a lasting decision, record it in `docs/decisions.md`. Move durable explanations into the relevant README or `docs/` page.
