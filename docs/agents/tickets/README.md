# Ticket Notes

Working and handoff notes for Jira tickets in progress, one file per ticket (for example `TCVP-3480.md`). Use them to carry context between agent sessions.

- Start each file with the goal, the decisions made so far, and the current status or next step.
- When the ticket is merged, move any lasting knowledge into the relevant topic file, then delete the ticket file.

Longer-lived, human-facing ticket material lives in `docs/jira-tickets/`.
