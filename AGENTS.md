# AGENTS.md

Instructions for AI coding agents working in this repository.

**Before starting work, read [docs/agents/agents.md](docs/agents/agents.md).** It indexes the project documentation for agents: architecture, related repositories, database ownership rules, workflows, and in-progress ticket notes. Open only the linked files that relate to your task.

When you learn something a future agent would need, add it under `docs/agents/` following [docs/agents/conventions.md](docs/agents/conventions.md). Keep this file as a short pointer.
